# Manga lettering fonts

Unmodified static fonts from [Google Fonts](https://github.com/google/fonts/tree/66928797f271fed5ee428544e7229685e2d90127/ofl), revision `66928797f271fed5ee428544e7229685e2d90127`:

- [Balsamiq Sans](https://github.com/balsamiq/balsamiqsans): handwritten dialogue.
- [PT Serif](https://www.paratype.com/fonts/pt/pt-serif): formal printed lettering.
- [Fira Sans Condensed](https://github.com/mozilla/Fira): narrow lettering.

Each family includes Regular, Bold, Italic and Bold Italic with Cyrillic, including Ё and ё. The original SIL Open Font License and copyright notice accompany each family in its `*-OFL.txt` file.
