qbutt media components

The exact runtime archive, file SHA256 values and source references are recorded
in media/component-lock.json. The pinned mpv, FFmpeg, ffprobe and yt-dlp executables
and prepared player profile are included in qbutt's installer and portable
archive. No upstream installer is run. Updates require an intentional lock change.

mpv
  Source: https://github.com/mpv-player/mpv/tree/b2c255c13e8e37952dbac6c34da56a690560378b
  qbutt builds this revision with the frozen MSYS2 CLANG64 dependency closure.
  Copyright and GPL/LGPL texts accompany this notice.
  The release's media-sources ZIP preserves the custom build recipe, exact source
  inputs, original MSYS2 PKGBUILDs and patches, package BUILDINFO/PKGINFO, source
  archives, VCS trees and Cargo dependencies for the linked runtime and static
  libraries. Its manifests bind those inputs to the bundled binary closure.
  component-lock.json pins that complete source archive by URL, size and SHA256.
  BUILDING.txt in the archive describes the recorded toolchain and rebuild steps.
  libplacebo by Niklas Haas and contributors is under LGPL version 2.1 or later;
  its pinned license is libplacebo-LGPL-2.1.txt.

FFmpeg and ffprobe
  GPL version 3 or later, shared MSYS2 CLANG64 FFmpeg 9.0.2-6 build.
  The original package BUILDINFO, PKGBUILD, patches and exact source archive are
  retained in the media-sources ZIP, together with its linked dependencies.
  Original package license texts accompany the DLLs under media/licenses/msys2.
  FFmpeg and ffprobe use the same DLL closure at media/; qbutt supplies that
  working directory explicitly when starting either tool.

yt-dlp
  Source: https://github.com/yt-dlp/yt-dlp/tree/2026.08.19
  The Windows executable combines yt-dlp and dependencies under GPL version 3+.
  Upstream Unlicense, GPL version 3 and third-party notices accompany this notice.
  The media-sources ZIP retains exact yt-dlp, CPython, PyInstaller, frozen Python
  package, curl native dependency and EJS source inputs and controlling recipes.
  Its manifest describes the verified binary/source bindings and their scope.

HTTPS trust store
  certifi 2026.7.22 supplies the pinned Mozilla CA collection under MPL-2.0.
  Source archive URL, SHA256 and PEM member are recorded under tlsTrustStore
  in component-lock.json; the PEM hash is recorded under bundledHashes.
  The exact source archive is also retained in the release media-sources ZIP
  under yt-dlp/source-export/sdists. certifi-MPL-2.0.txt retains its full license.
  mpv verifies HTTPS certificates and host names using this collection together
  with native Windows trust. Certificate verification remains enabled.

ModernX and the shader profile
  ModernX: https://github.com/zydezu/ModernX
  Its mpv-osc-modern ancestor by maoiscat is published under LGPL-2.1:
  https://github.com/maoiscat/mpv-osc-modern
  That ancestor's exact license text is retained in
  ModernX-ancestor-LGPL-2.1.txt. This attribution records the upstream lineage;
  it does not assign a new license to the later ModernX forks.
  Attribution in scripts/modernx.lua is retained. This qbutt adaptation replaces
  its independent download subprocess with a request to qbutt's download queue.
  Anime4K and FSR shaders retain their individual license headers in shaders/.
  Fluent System Icons: https://github.com/microsoft/fluentui-system-icons
  Its MIT license accompanies this notice.

qbutt adaptations
  Corresponding sources are maintained in the qbutt source distribution under
  resources/media/profile and copied into the release media-sources ZIP with
  the actual prepared manager sources and binary/source mapping.
  The imported profile snapshot is identified by
  profileSourceRevision in the component lock; private history is not distributed.
  qbutt supplies an asynchronous read-only GPU policy and stores generated runtime
  data only in qbutt's data directory. No global mpv profile, registry environment
  variables or machine-local shader benchmark profile are installed.

Frame generation
  Manager and bootstrap sources, Cargo locks, build recipes and generated notices
  are maintained under resources/media/profile/tools in the source distribution.
  The compiled Rust notices and pinned standard-library notice accompany the
  executables under media/profile/tools/bin. Runtime-specific notices are copied
  by the manager from profile/tools/framegen-manager/notices.
  The modified Intel VSOV plugin has complete source/build instructions and
  modification provenance under media/profile/tools/framegen-vsov.
  The Intel RIFE graph has provenance under media/profile/framegen/models/openvino.
  Additional runtime downloads are individually pinned in the manager catalog.
