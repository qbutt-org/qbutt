# qbutt

qbutt — A ButtTorrent Client.

Торрент-клиент для Windows с одновременной загрузкой через выбранные узлы Mihomo и обычную сеть. Поддерживает стандартные подписки, докачку с использованием уже имеющихся файлов и светлую и тёмную темы с режимом «Система».

## Установка

Скачайте [последний релиз](https://github.com/qbutt-org/qbutt/releases/latest):

- **Установщик EXE** установит qbutt и добавит ярлык в меню «Пуск».
- **Portable ZIP** достаточно распаковать и запустить `qbutt.exe`. Настройки хранятся в папке `profile` рядом с программой.

У qbutt отдельный профиль. Настройки и торренты из другого клиента можно перенести через **Файл → Импорт профиля**.

## Возможности

- Добавьте подписку в **Настройки → Соединение**, отметьте нужные узлы и включите Mihomo. Выбранные узлы работают одновременно с обычным подключением.
- Чтобы докачать имеющиеся файлы, добавьте торрент как обычно и укажите папку с файлами: qbutt проверит их и загрузит недостающее. Для расширенного восстановления остановите добавленный торрент и откройте **Восстановить файлы** из его меню.
- В **Настройки → Загрузки** открытие `.torrent` из папки «Рабочий стол» включено по умолчанию. После открытия исходный `.torrent` удаляется; папку и переключатель можно изменить.
- Там же можно включить полоску прогресса поверх окон. Завершённые торренты по умолчанию удаляются из списка с сохранением файлов; это можно отключить.
- Обновления доступны через меню **Справка**. Установленная версия скачивает EXE в фоне и предлагает обновить и перезапустить программу; portable ZIP обновляется вручную.

Для подключения подходит обычная подписка Mihomo: аккаунт в конкретном сервисе не нужен. Системные VPN-настройки из подписки не применяются. Дополнительные сетевые настройки доступны по необходимости; входящие подключения через публичный шлюз требуют отдельно настроенного шлюза.

## Разработка

Windows x64, Visual Studio 2022 с C++ и Windows SDK, CMake, Git, Python 3.12 и Bun:

```powershell
./scripts/build-windows.ps1
```

Скрипт использует зависимости из `upstream-lock.json` и собирает portable ZIP и EXE-установщик локально. `-BuildRoot` задаёт папку сборки, `-ArtifactRoot` — папку готовых файлов. Служебные сведения о сборке остаются локально.

См. [правила проекта](AGENTS.md), [архитектуру](docs/qbutt-architecture.md) и [интеграционные проверки](tests/README.md). Автоматического запуска GitHub Actions нет.
