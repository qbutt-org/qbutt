# qbutt interface icons

Interface glyphs use a 24 × 24 viewBox in a 32 × 32 SVG, with rounded 1.8-unit strokes. Keep the shape legible at 16 pixels. Neutral strokes are `#465669` in the root file and `#c8d4df` in `dark/`. Reserve the blue accent (`#009df7` in light mode) for the active part of an action; use semantic colors only for status and destructive actions.

The built-in theme selects `dark/<name>.svg` automatically. Add both variants to `icons.qrc` when creating a new interface icon. Brand and flag assets keep their own colors.
